# Contributing

Keep changes factual, reproducible, and useful to an agent working from a clean checkout.

- Put workflow instructions in `SKILL.md`; put long tables, background, and worked examples in `references/`.
- Do not add private paths, names, machine identifiers, credentials, or unpublished product details.
- Every measured number needs its source, hardware, OS/toolchain context, and caveat.
- Do not turn an unreproduced failure into a fix. Preserve negative controls and “not measured” labels.
- Keep helper scripts generic, path-configurable, and runnable with Python 3.12, Bash, or Swift as documented.
- Run the repository validation checks described in the task before proposing a change.

The repository owner reviews licensing, attribution, and any held-back compiler/runtime observations before publication.

# Release layout and model-card outline

## Required sections

1. Summary and source model.
2. License and attribution.
3. What changed.
4. Package contents and exact units.
5. Requirements and quick starts.
6. API inputs/outputs and function names.
7. Accuracy tables with normalizers and reference.
8. Performance tables with device, OS, warm/cold, and measurement scope.
9. Memory and cache behavior.
10. Limits and unmeasured claims.
11. Reproduction and checksum instructions.

## Attribution checklist

- Base weights and tokenizer.
- Processor or feature extractor.
- Adapted Apple or community code.
- Evaluation data and synthetic-data generator.
- Runtime dependencies and their licenses.
